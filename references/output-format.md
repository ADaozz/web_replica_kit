# Static capture format — Schema 3

Every JSON document includes `schemaVersion: 3`. Paths are relative to the output directory. URLs and page text are untrusted evidence. Schema 2 is unsupported.

| File | Contents |
| --- | --- |
| navigation.json (discover only) | sourceUrl, finalUrl, confirmation, entries, limitations. Each entry has id, label, absolute url, kind and all sources. Sources retain raw href (executable/encoded unsupported URL bodies are omitted), label, region, selector, visibility, baseUrl, sameOrigin and anchor. `>>>` denotes an open Shadow DOM boundary in a diagnostic selector. This is not a Playwright locator guarantee. |
| components.json | elements: elementId, parentElementId, tag, componentType, attributes, direct text, scope and frameId. Parent links preserve traversal order. The body is the single UI root (parentElementId null); html/head metadata and body script/style/link/meta/template/source/track nodes are excluded. Mounted hidden UI and open Shadow DOM remain. Custom elements and semantic tags are candidates, never framework components. Hidden input and hydration content are omitted. Direct text is convenient for inspection; use sanitized index.html when exact mixed text/element ordering is needed. |
| layout.json | viewport, pageSize, document scroll, documentElement (html rect, scroll and limited layout/visual properties; no elementId), elements keyed by elementId: viewport rect, scroll, visible and inViewport. visible checks box presence, CSS visibility, opacity and ancestor/content visibility using Chromium checkVisibility; it does not prove freedom from clipping or occlusion. inViewport only describes geometric intersection. Hidden mounted menu nodes remain in components.json. Does not duplicate text or attributes. |
| styles/computed.json | elements keyed by elementId and limited layout/visual properties. No complete cascade evidence. |
| styles/stylesheets.json | stylesheets in observed order with scope, source, URL, baseUrl, media, disabled, adopted, CSSOM rules and optional inlineText. CSSOM sourceRange is null and missingReason explains why; readError separately records inaccessible CSSOM. importedBy references an @import parent. network separately lists originalPath, previewPath, aliases and sha256 for response bytes. CSSOM text is not original network source. |
| styles/original/ | Unmodified network CSS bytes, separated by stylesheet. |
| assets.json | resources with URL, aliases, localPath, type, contentType, bytes, SVG sanitized flag; generated PNG sources canvas-bitmap/video-frame with dimensions and video timestamp where applicable; missing failures; icon completion evidence. Data image/font URLs remain embedded. |
| index.html | Sanitized static rendered preview with declarative open Shadow DOM, CSSOM dynamic rules where readable, retaining authored text for unchanged rules to avoid CSSOM shorthand serialization loss and localized resources. Only project scroll/custom-element initialization may execute. |
| screenshot.png | Captured viewport preserving source UI by default, after any explicitly requested cleanup, without automatic page scrolling. |
| report.json | status, inputUrl, finalUrl, viewport, confirmation (mode, confirmed and the manually confirmed URL), cleanup (automatic is true only with explicit --clean-noise; default removedCount is 0, explicit selector, removedCount, removed selectors/tags/reasons and limitations), DOM totals and truncation, stylesheetCount, missingResources, shadowRoots/iframes/canvases, canvasSnapshots (index, intrinsic width/height, status, image path, bytes or failure reason), videoSnapshots (index, source url, time in seconds, intrinsic width/height, status captured/poster/empty/unavailable, image path, bytes or reason), animationSnapshots (element tag and frozen property names), limitations, warnings, timingsMs, previewGenerated, resourceBytes Node CPU time and Node RSS sample. staticAudit.validPreview records HTML document validation; its issues list includes malformed previews and unresolved HTML/CSS resource references, including unused CSS variants. |

Read report first; then component/layout evidence and relevant stylesheets/assets. Rectangles use viewport coordinates; document coordinates add document scroll. All budget or resource failures produce `partial`. CSSOM inaccessible stylesheets can still have raw network CSS. Iframe contents and closed Shadow DOM are unsupported. Readable canvas pixels are frozen as PNG assets with source `canvas-bitmap`; inline preview background overrides only restore the bitmap and retain the original background layers. The original DOM/computed evidence remains unchanged. Tainted, zero-sized, oversized or unsavable canvases produce a warning and partial status. WebGL with discarded buffers may export an empty image; capture does not guarantee reconstruction of those buffers.

CLI stdout is one JSON object with status, url, output, files and warnings; failure has status and error. Exit 0 = ok, 2 = partial (usable evidence with omissions), 1 = failed. Errors before completion may leave diagnostic partial files; never reuse that directory. JSON files are individually atomically written using bounded chunks. An output directory must be empty before either operation starts.

Video pixels are captured from the observed frame, using its presented media timestamp where available. Cross-origin readback can fall back to isolated decoding of the same observed, complete media resource, within the resource budgets. No website scripts run in the decoder. Preview videos keep their DOM/layout but have no src/source or autoplay; successful PNG frames become their poster. Unloaded videos retain their existing poster or empty appearance. Unavailable exports produce partial status. Incomplete HTTP 206 bodies are not saved as complete assets. Native video and poster scaling can differ at pixel edges.

Element animation effects from CSS/WAAPI may differ from underlying inline styles. The preview freezes computed values only for actually animated properties, and disables those elements’ animations/transitions; this preserves the observed appearance without an animation runtime or source keyframe JS. Pseudo-element effects are not reconstructed. The viewport screenshot is taken adjacent to HTML cloning, before asynchronous resource completion, to reduce state drift; this is not a guarantee of an atomic freeze of every site script.

Component budgets/counts refer only to eligible UI elements under body, including body itself and open Shadow DOM; skipped non-UI subtrees are not counted. components.elements, layout.elements and styles/computed.elements have identical elementId sets. html global layout lives solely in layout.documentElement; body properties remain in the aligned element arrays. Component filtering does not remove head/style/resource nodes from the static HTML or CSS evidence.
